CANDELA — ПРЕДВАРИТЕЛЬНАЯ ВЕРСИЯ

Candela — визуализатор и редактор сценического света: приборы GDTF, сцены MVR, физически корректный свет (канделы,
люксы), объёмные лучи в дыму, DMX- и силовая коммутация, управление с пультов в реальном времени (Art-Net, sACN, OSC,
PSN).

Это предварительная версия для знакомства с редактором. Между версиями многое меняется, некоторые части ещё не
закончены (см. «Известные ограничения» в документации). Сохраняйте проекты почаще; кроме того, редактор сам
сохраняет работу каждые 5 минут.


СИСТЕМНЫЕ ТРЕБОВАНИЯ

  * Windows 10 или Windows 11, 64-бит.
  * Видеокарта с драйвером Vulkan 1.3: NVIDIA GeForce GTX 900 и новее, AMD Radeon RX 400 и новее, Intel UHD/Iris Xe
    (11-е поколение) или Arc. Установите последний драйвер с сайта производителя видеокарты.
  * 8 ГБ оперативной памяти (рекомендуется 16 ГБ), около 400 МБ на диске для программы.


ЧТО ДЕЛАЕТ ПРОГРАММА УСТАНОВКИ

  * Устанавливает Candela для всех пользователей (C:\Program Files\Candela, нужны права администратора) или только
    для вас (%LOCALAPPDATA%\Programs\Candela) — выбор на следующей странице.
  * Устанавливает среду выполнения Microsoft Visual C++ 2015-2022 (x64), если её нет: она нужна библиотекам
    интерфейса редактора.
  * Создаёт ярлыки в меню «Пуск» (Candela, Командная строка Candela, Прочтите, Документация) и, по желанию, на
    рабочем столе.
  * Открывает проекты .candela в Candela и добавляет «Открыть с помощью Candela» для сцен .mvr (по желанию).
  * Добавляет правило брандмауэра Windows, чтобы пульт мог передавать в Candela Art-Net, sACN, OSC и PSN (по
    желанию; подробности — на отдельной странице).
  * Устанавливает пример сцены («Фокина.mvr», театральная световая партитура на 91 прибор) с нужными ей файлами GDTF.


БИБЛИОТЕКА ПРИБОРОВ

Candela строит приборы по их файлам GDTF. Полная библиотека (около 1100 приборов, 1,8 ГБ) в установку не входит.
При первом запуске Candela спросит, в какой папке лежат ваши файлы .gdtf, или создаст для них папку
«Документы\Candela\Fixture Library». Файлы GDTF публикуют производители — на https://gdtf-share.com и на своих сайтах.


ЭТА ВЕРСИЯ НЕ ПОДПИСАНА

При запуске программы установки Windows SmartScreen может написать «Система Windows защитила ваш компьютер».
Нажмите «Подробнее», затем «Выполнить в любом случае».


ГДЕ ХРАНЯТСЯ ВАШИ ФАЙЛЫ

  * Настройки и раскладки окон: %APPDATA%\Candela
  * Кэш, автосохранения, журналы и отчёты об ошибках: %LOCALAPPDATA%\Candela
  * Ваши проекты — там, где вы их сохраняете. При удалении программы проекты и библиотека приборов не удаляются.


ЧТО-ТО НЕ ТАК?

Сообщите о проблеме на https://github.com/nikitasa228/gdtf/issues и приложите журнал
(%LOCALAPPDATA%\Candela\logs\candela-app.log) или отчёт об ошибке, который показал редактор.


СТОРОННИЕ КОМПОНЕНТЫ

Candela использует компоненты с открытым исходным кодом (.NET, Silk.NET, Dear ImGui, GLFW, ImGuizmo, Hexa.NET,
shaderc, Assimp, SharpGLTF, StbImageSharp, шрифты Inter и Lucide) на условиях их лицензий; см. файл
THIRD-PARTY-NOTICES.txt в папке установки.
